# 爆音アラーム

iPhoneのSafariで動く、止めにくい爆音アラームのWebアプリです。

## 使い方

1. iPhoneのSafariでページを開く
2. 共有ボタン →「ホーム画面に追加」（なくても動きます）
3. 本体の音量を最大にする
4. 時刻と音を選んで「アラームをセット」
5. 画面を開いたまま、充電しながら置いておく
6. 鳴ったら「3秒長押しで止める」

## しくみ

- 音声は `<audio>` 要素で再生します。iOSではこの方法だとサイレントスイッチがオンでも鳴ります
- 音はその場で合成した矩形波のWAVを、音割れ寸前まで持ち上げて鳴らします
- セット中は無音を流し続け、画面ロック・バックグラウンドでもページを止められにくくしています
- Screen Wake Lock APIで、セット中は画面の自動ロックを止めます
- ロック画面の一時停止ボタンでは止まりません

## 制限

- Webからは本体の音量を上げられません
- アプリを閉じている間は鳴りません。Webプッシュ通知は送れますが、通知音は普通の音で爆音にはできず、送るためのサーバーも必要です
- 画面ロック中や他アプリ使用中は、iOSの判断で再生が止まることがあります。画面をつけたまま置いておくのが確実です

## 公開

GitHub Pagesで `main` ブランチのルートをそのまま公開します。ビルドは不要です。
